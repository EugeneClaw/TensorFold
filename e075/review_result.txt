FINDINGS (cross-referenced from the Q&A below)

F1 (BLOCKING) — _mla_branch sdpa: gap keys enter the softmax with logit exactly 0, not -inf.
  Gap rows write zero latents; keys_values is a pure expansion (lat @ kv_b, no bias/norm), so k_gap = 0, v_gap = 0, and logit_gap = (q·0)·scale = 0. The causal mask (`causal = arange(end) <= q_pos`) excludes only the future — nothing excludes gaps. Per-query softmax weight of each gap key = exp(0 − M), M = max real logit.
  Quantified at the stated operating point (n=25K, fed=10K, G≈15K gaps):
  - Peaked query, M ≈ 15: inflation = 15000·exp(−15) ≈ 4.6e−3 vs real mass O(1–30). Negligible.
  - Flat/diffuse query, M ≈ 3–5 (early layers, aggregation heads — exactly the heads long-context recall lives in): inflation ≈ 15000·exp(−4) ≈ 274 vs real mass O(1–30) → real weights renormalized down 10–100x. Since v_gap = 0, the numerator is untouched: output is a per-query scalar shrink of the attention contribution toward 0.
  Residual + post_norm rms_norm partially reabsorb the scale, so end-task metrics drift rather than collapse — the silent-corruption profile, not the crash profile. The corruption is baked into every fed row's layer output, hence into downstream layers, the MTP raws, and the seed hidden — permanent for the session. (Decode itself is safe via the indexer path: mixed blocks pool to ≈ the real key, full-gap blocks score −9984 and are never selected — the pool got this right; the prefill sdpa didn't.)
  Fix: keep a key-validity bool over [0, end): True for all cached/prefix rows and for feed_mask positions of this prompt; `causal = causal & valid[None, :]` and pass as a bool mask (MLX bool mask = keep-semantics). O(end) bools per window, free.

F2 (BLOCKING to verify; clamp costs one line) — MTP cache over-trim.
  mtp_offset = fed + generated − 2048·trims; backbone = n + generated − 2048·trims; difference is constant 6076. After two window trims with little generation: 4165 − 4096 = 69 ≥ 0 — a 69-row margin. Any trim site that removes >2 windows in one call (copy-round compaction, reclaim-to-absolute-position, prefix-restore paths) drives MTPCache.offset negative → negative slicing wraps to the array tail = silent corruption, or a crash.
  Fix: `count = min(count, self.offset)` in MTPCache.trim plus `assert self.offset >= 0`; add the trim-storm test (below).

F3 (ADVISORY, and the unlock for the Q8 win) — KDA decay-only invariant is violated on the first taps−1 rows of every gap run.
  proj is zeroed at gaps BEFORE conv, but conv is causal with taps: a gap row within taps−1 of the preceding fed row has a window containing that row's real input → co ≠ 0 → q/k/v ≠ 0 → a ghost β·v kᵀ update (double-counts the neighbor) and a non-decay gate g. Rows deeper in the run are exactly decay-only; gap outputs are discarded (`y = y[rel]`) so only state contamination persists, systematically, ~2·(#runs)·34 ghost rank-1 updates at the probe scale. Your own derivation assumed the whole window is zeros — it is, except at run heads.
  Fix: zero post-conv rows at gap positions before the scan (`co = co * span_mask`, or pass a validity mask into kda_rows). Then β·v kᵀ = 0.5·0 = 0 and g = exp(lb·sigmoid(A·dt_bias)) is pure decay, exactly as you derived — and provably so.

F4 (ADVISORY) — mask hygiene in the scorer. `_row` builds a bf16 0/1 mask; under additive float-mask semantics that's a uniform +1.0 logit (softmax-invariant only because it's all-True today). Use bool. Also `return importance, elapsed` — `elapsed` is never defined in the shown file; verify it's not a NameError in the real one.

F5 (ADVISORY) — doc/code mismatch: prose says mean_lookahead(max_head(·)); code does `mx.max(weights, axis=1)` then `mx.mean(..., axis=0)` = max over lookahead, MEAN over heads. Both defensible; pick one and align with the paper.

F6 (ADVISORY) — absorb nxt for the final fed row has no successor (idx+1 = n). If it isn't excluded, one bogus (raw, nxt) pair enters draft context silently. Verify it's dropped.

Can a zero block win selection? score(gap) = relu(q·0) + gate ≈ −9984; score(real) ≥ 0 + gate_real, and gate_real ≥ −|ape|max ≈ −2048 at span 2048 → separation ≈ 7936 nats → exp underflows to exact 0.0 in fp32. Gap blocks enter only if k > #real blocks (degenerate: needs fed < 4k rows in a window); if selected anyway, their softmax weight is exp(−9984 − max) = 0 and v = 0 — pure slot waste, zero numeric contribution. Worst case is recall dilution, never corruption.
